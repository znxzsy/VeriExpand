# Public release boundary

This repository contains only original documentation and a small fictional example prepared for public sharing. Its Git history starts from these files.

Do not add private datasets, student images, annotations, model weights, credentials, service addresses, internal configurations, research logs, full manuscripts or core implementations.

`PUBLIC_FILES.txt` records the intended distribution. The ignore rules default to excluding unlisted content; maintain the allowlist deliberately. Ignore rules are not a security scanner and do not remove already tracked files.

The example performs no external requests and consumes no private artifacts. Its outputs are fictional, not measured research results.
